# 한컴독스 서식정리 · 자간 정리

**먼저 `hancomdocs-edit` 스킬을 불러온다**(플러그인으로 설치했으면 `hancomdocs:hancomdocs-edit`). 문서 여는 법, 찾아 바꾸기 사용법, 단축키(`alt+c` 모양 복사, `alt+shift+n/w` 자간), 함정은 거기 있고 이 문서는 그것을 전제로 한다. 실측은 2026-09-29 연습 문서, macOS 크롬 기준이다.

## 0. 서식 기준 묻기

AskUserQuestion 한 번에 묶어 묻는다.
- **문단 스타일**: 단계별(1·2·3단계) 기준 문단 또는 스타일 이름. 기호 체계 기본값은 □ / ◦ / -.
- **자간 한도**: 줄 넘침을 자간으로 당길 때 어디까지 줄일지(권장 -10%까지). 한도를 넘어야 하면 멈추고 묻는다.

## 1. 서식정리: 손으로 친 기호 → 문서의 진짜 단계 서식

hwpable-html 원고는 `□ `·`◦ `·`- `를 글자로 쳐서 단계를 표시한다. 붙여넣은 뒤 이 기호를 지우고 **실전 문서에 이미 있는 단계별 서식을 모양 복사로 입힌다**. 웹 한글에서는 □·◦·- 글머리표를 새로 정의할 수 없으므로 문서에 있는 서식을 옮기는 방식이 기본이다.

단계 기호 기본값은 **1단계 □ / 2단계 ◦ / 3단계 -**이다. 0절에서 유저가 다르게 답하면 그 답을 따른다.

### 1-1. 기준 문단 찾기(단계마다 1개)

1. 실전 문서에서 이미 제대로 된 1·2·3단계 문단을 하나씩 찾는다. 제대로 된 문단은 기호가 글자가 아니라 서식이다. 확인 방법은 두 가지다.
   - 그 문단에 커서를 두면 도구 모음의 글머리표 또는 문단 번호 버튼이 눌려 있다.
   - `hancomdocs-edit` 1절 방법으로 복사한 평문(`pbpaste`)에 기호가 안 나온다(Claude Code + macOS에서만).
2. 단계별 기준 문단의 고유 문구를 스크래치패드에 적어 둔다. 못 찾거나 애매하면 유저에게 "□/◦/- 단계 기준 문단"을 하나씩 짚어 달라고 한다.

### 1-2. 손으로 친 기호 지우기

- 선택 영역이 없는 상태에서 찾아 바꾸기로 `- (키워드)` → `(키워드)`처럼 **기호+키워드 단위**로 모두 바꾸기 한다. `- `만 넣고 모두 바꾸기 하면 본문 속 하이픈까지 지워지므로 하지 않는다.
- 키워드가 겹치면 **다음 찾기 → 바꾸기**로 한 곳씩 한다.
- 대안: 해당 문단을 찾은 뒤 `Home` → `Delete` 두 번(기호와 공백). `Home`은 글머리표 뒤 첫 글자로 간다.

### 1-3. 모양 복사로 단계 서식 입히기(단계별로 반복)

1. 찾기로 **기준 문단**에 커서를 둔다(선택은 `Right`로 푼다).
2. `alt+c`(또는 `편집` 메뉴 → `모양 복사...`) → 대화상자에서 **`문단 모양`** 라디오 → `복사`. 글자 모양까지 복사하면 원고의 굵게·파란 글씨가 덮이므로 문단 모양만 고른다.
3. 대상 문단을 **선택한다**. 커서만 두고 모양 복사를 누르면 복사 대화상자가 다시 뜰 뿐 적용되지 않는다.
   - 한 문단: 찾기로 그 문단의 문구를 선택한다.
   - 이어진 여러 문단: 첫 문단 첫머리를 클릭하고 마지막 문단 끝을 shift+클릭한다(좌표는 방금 찍은 스크린샷 기준). 또는 `Home` 뒤 `shift+Down`을 1초 간격으로 줄 수만큼 누르고 `shift+End`.
4. `alt+c`(또는 `편집` → `모양 복사...`)를 다시 누르면 곧바로 적용된다(글머리표·내어쓰기·여백이 함께 옮겨짐). 복사해 둔 모양은 다음 복사 전까지 유지되므로, 같은 단계의 떨어진 문단들은 3~4만 반복한다.
5. 다음 단계로 넘어갈 때 1부터 다시 한다(기준 문단 바꿔 복사).
6. 스크린샷으로 단계별 기호·들여쓰기·둘째 줄 내어쓰기를 확인한다.

### 1-4. 기준 문단이 없을 때: 프리셋

- `서식` → `글머리표 모양...`은 ●○■◆✓ 같은 프리셋만 있고 □·◦·- 모양을 새로 정의하는 기능은 없다. 적용하면 내어쓰기가 자동으로 붙는다. 글머리표는 한 단계뿐이라 수준 증가/감소가 먹지 않는다.
- `서식` → `문단 번호 모양...`에는 1./가./1)/가) 같은 여러 단계 프리셋이 있다. 대화상자 항목은 `read_page`(interactive)로 참조를 받는다(프리셋은 menuitem "1"~"10").
- **도구 모음의 `한 수준 감소`가 한 단계 아래로(1. → 가.) 내린다.** 이름과 방향이 반대다. `한 수준 증가`는 위로 올린다. 서식 메뉴 쪽 항목은 눌러도 반응이 없어서 도구 모음 버튼(`find`로 "한 수준 증가/감소" 참조)을 쓴다. `Ctrl+Num +/-` 단축키는 맥 키보드에 없다.
- 프리셋은 유저의 □/◦/- 체계와 다르므로 먼저 유저에게 묻는다.

## 2. 줄 넘침 정리: 자간 줄이기

한두 글자만 다음 줄로 떨어지거나 표 칸 글이 한 글자 차이로 줄바꿈되면, 그 문단(칸)만 자간을 줄여 한 줄 덜 쓰게 만든다. 유저가 손으로 하던 일이다. **내가 판단해서 한다.**

### 2-1. 대상 고르기

붙여넣기·서식정리를 마친 구간을 스크린샷(`zoom`)으로 훑으며 아래에 해당하는 곳을 고른다.
- 문단 마지막 줄이 **1~5글자**(예: "함.", "를 확보함.")뿐인 경우
- 표 칸에서 한두 글자가 둘째 줄로 떨어져 행이 불필요하게 높아진 경우
- 불릿 첫 줄의 키워드 `(키워드)`가 줄 끝에서 갈라진 경우

마지막 줄이 절반 이상 차 있으면 손대지 않는다. 자간으로 줄 수가 줄지 않을 만큼 긴 문단도 건너뛰고 보고에 적는다.

### 2-2. 줄이기

1. 대상 문단을 선택한다: 찾기로 문단 안 고유 문구에 커서 → 선택 풀기(`Right`) → `Home` → `shift+Down`(줄 수만큼, 1초 간격) → `shift+End`. 표 칸은 칸 안을 클릭한 뒤 같은 방법으로 칸 글만 잡는다.
2. `alt+shift+n`을 **1초 간격으로 한 번씩** 누르고, 누를 때마다 `zoom`으로 떨어진 글자가 윗줄로 올라왔는지 본다. 올라오면 멈춘다.
3. 0절에서 정한 **자간 한도**(기본 -10%)에 닿아도 안 올라오면 `alt+shift+w`로 원래대로 돌리고 보고에 적는다.
4. 값 확인·직접 입력: `서식` → `글자 모양...` → `자간` 칸(참조는 `find`로 "자간"). 한 번에 크게 바꿀 때는 이 칸에 값을 넣고 확인하는 편이 빠르다.
5. 이미 자간이 줄어 있는 문단(글자 모양 대화상자 자간이 0이 아님)은 한도까지 남은 만큼만 줄인다.

### 2-3. 원칙

- 문단 전체에 같은 값을 준다. 한 줄이나 몇 글자만 줄이면 글자 간격이 들쭉날쭉해진다.
- 글자 크기·장평은 바꾸지 않는다. 크기를 줄여야 할 것 같으면 유저에게 묻는다.
- 바꾼 곳(문단 첫 문구와 자간 값)을 목록으로 남겨 보고한다.

## 3. 검증

1. 서식정리한 구간 평문에 `- (`·`◦ [`·`□ ` 같은 손으로 친 기호가 남지 않았는지 확인한다(셸이 없으면 찾아 바꾸기 **다음 찾기**로).
2. 보고에 넣을 것: 단계별로 서식을 입힌 문단 수, 기준 문단이 없어 프리셋을 쓴 곳, 자간을 바꾼 곳과 값, 한도 안에서 못 맞춘 곳.
