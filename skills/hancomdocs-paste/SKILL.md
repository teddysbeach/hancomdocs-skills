# 한컴독스 붙여넣기 (hwpable-html → 웹 한글)

hwpable-html로 만든 HTML을 복사해 한컴독스에 붙여넣는 흐름이다(2026-09-29 연습 문서, macOS 크롬 실측). 서식(글꼴·색·160% 줄 간격·표 선)은 그대로 들어간다.

**먼저 `hancomdocs-edit` 스킬을 불러온다**(플러그인으로 설치했으면 `hancomdocs:hancomdocs-edit`). 문서 여는 법, 찾아 바꾸기 사용법, 단축키, 함정은 거기 있고 이 문서는 그것을 전제로 한다.

## 0. 서식 기준 묻기

붙여넣기 전에 AskUserQuestion 한 번으로 묻는다.
- **글자 크기**: 본문 글자 크기(예: 12pt)와 표 안 글자 크기(예: 10~11pt), 줄 간격(예: 160%)

답은 작업 내내 기준으로 쓰고, 붙여넣은 글의 크기·간격이 다르면 맞춘다. 붙여넣은 뒤 글머리표 정리까지 할 거면 `hancomdocs-format`의 0절 질문도 같은 AskUserQuestion에 묶는다.

## 1. HTML 열고 복사

**Claude Code + macOS**
1. HTML은 크롬 확장이 열 수 있게 스크래치패드에서 로컬 서버로 띄운다: `cd <scratchpad>/web && python3 -m http.server 8765` (백그라운드) → `http://localhost:8765/<파일>.html`.
2. 툴바의 **본문 복사**(전체)나 블록 옆 **이 블록 복사** 버튼을 `find` 참조로 누른다. 여러 블록이면 `javascript_tool`로 `.hwp-blockcopy` 버튼 목록과 부모 글을 먼저 뽑아 몇 번째 버튼인지 고른다.
3. `osascript -e 'clipboard info'`에 `«class HTML»`이 있는지, `pbpaste`로 글이 맞는지 확인한다.

**셸이 없을 때(Claude 앱 등)**: 유저에게 hwpable HTML 파일을 크롬에서 열어 달라고 하고(또는 아티팩트 링크), 그 탭의 **본문 복사/이 블록 복사** 버튼을 누른다. 붙여넣은 결과는 스크린샷으로 확인한다.

## 2. 붙여넣기

- **새 위치에 넣기**: 찾기로 앞 문단 끝에 커서를 두고(`End`) `cmd+v`를 누른다.
- **기존 문단 바꾸기**: 찾아 바꾸기 대화상자의 찾을 내용에 **옛 문단 전체**를 넣고 **다음 찾기**를 누른다. 문단 전체가 선택되면(상태표시줄 "71/2357 글자"처럼 선택 글자 수가 뜸) 대화상자를 닫고 `cmd+v`를 누른다. 붙여넣으면 뒤에 **빈 문단이 하나 생기므로** 곧바로 `BackSpace` 한 번으로 지운다.
- 붙여넣은 글은 hwpable 문단 아래 간격을 그대로 가져온다. 문단 사이가 벌어져 보이는 것은 원래 HTML 서식이다.

## 3. 표: 글자처럼 취급 + 표 문단 줄 간격 160%

붙여넣은 표는 '글자처럼 취급'이 꺼진 채 들어온다. 표마다 아래 두 단계를 한 쌍으로 한다.

1. **글자처럼 취급 켜기**: 표 안 칸을 마우스로 클릭(칸 안 클릭은 된다) → `표` 메뉴 → `표/셀 속성...` → 기본 탭 `글자처럼 취급` 체크 → 확인.
2. 켜는 순간 표가 뒤 문단과 **겹친다**. 표를 품은 문단의 줄 간격이 붙여넣기 때 **고정 값 19.2pt**로 들어와 있어서다. 이 문단을 160%로 바꾼다.
   - 커서 두기: 찾아 바꾸기로 **표 바로 위 문단**(보통 `[표] 제목` 줄)의 고유 문구를 **다음 찾기** → 닫기 → `End` → `Right`. 이제 커서가 표 문단에 있다. 표 칸 안이나 표 옆 클릭으로는 이 문단에 커서가 가지 않았다.
   - 줄 간격 바꾸기: `서식` 메뉴 → `문단 모양...` → 줄 간격 콤보를 `글자에 따라`로 → 값 칸 triple_click 후 `160` → 확인. 대화상자를 열었을 때 줄 간격이 "고정 값 19.2pt"로 보이면 커서가 맞는 문단에 있는 것이다.
   - 도구 모음의 줄 간격 단위 드롭다운은 열리지 않았다. 대화상자를 쓴다.
3. 스크린샷으로 표 아래 글이 표에 겹치지 않는지 확인한다.
4. 글자처럼 취급한 표는 쪽 끝에 들어가지 않으면 통째로 다음 쪽으로 넘어가 앞쪽에 빈자리가 생긴다. 유저에게 알린다.

## 4. 표 폭 맞추기

- 표/셀 속성 기본 탭의 너비는 회색으로 잠겨 있어 숫자로 바꿀 수 없다. 셀 탭 너비는 칸마다 따로다.
- 셀 블록 뒤 `ctrl+→`·`alt+→`로 표 크기가 바뀌지 않았다.
- **표 오른쪽 테두리를 마우스로 끌면 된다**(`left_click_drag`). 본문 오른쪽 끝(다른 표·본문 글 오른쪽 끝의 x좌표)까지 끈다. 100% 배율에서 1px이 약 0.26mm라 몇 px 어긋날 수 있다. 정확한 폭이 필요하면 유저에게 맡긴다.
- 폭 조정은 유저가 직접 하겠다고 하면 건너뛰고, 표마다 현재 폭(표/셀 속성 기본 탭의 너비 mm)만 알려 준다.

## 5. 마무리

`hancomdocs-edit`의 마무리 검증을 따른다. 보고에는 붙여넣은 위치, 글자처럼 취급·줄 간격을 바꾼 표 목록, 다음 쪽으로 넘어간 표, 폭을 못 맞춘 표를 넣는다.
