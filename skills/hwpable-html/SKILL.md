# HWP-able HTML 서식 변환기

유저가 제공한 텍스트를 HWP(한글) 복사·붙여넣기가 깨지지 않는 HTML 문서로 변환한다.

## 핵심 원칙

이 스킬은 **순수 서식 변환기**다. 유저가 건넨 텍스트의 단어·문장·어순·말투·경어체를 단 하나도 바꾸지 않는다. 내용 생성, 윤색, 요약, 재구성, 문단 순서 변경 모두 금지다. 글의 흐름과 구조는 유저(또는 상위 에이전트)가 이미 결정한 상태이므로 그대로 따른다.

## 실행 흐름

### 1단계: 리소스 로드

이 SKILL.md와 같은 디렉토리에 있는 아래 파일들을 읽는다.

| 파일 | 용도 |
|------|------|
| `references/formatting-guide.md` | 구조, 뎁스, 테이블, 기호, 문장 스타일 통합 가이드 |
| `options/color-presets.md` | 테이블 컬러 프리셋 목록 |
| `templates/base.html` | HTML 뼈대 (style + script 인라인) |
| `references/org-chart.md` | 구성도(추진조직표) 모드 — 조직도 요청일 때만 읽는다 |
| `scripts/orgchart.py` | 구성도 생성기 (spec.json → HWP용 `<table>`) |

상대경로 실패 시 Glob 폴백:
```
**/hwpable-html/references/formatting-guide.md
**/hwpable-html/options/color-presets.md
**/hwpable-html/templates/base.html
```

### 2단계: 서식 스타일 선택

유저에게 구조 뎁스 기호 스타일을 질문한다.

> 서식 스타일을 선택해주세요.
> 1. 디폴트형 — 뎁스1: ㅁ, 뎁스2: ㅇ, 뎁스3: -
> 2. 올드형 — 뎁스1: (가), 뎁스2: ①, 뎁스3: ㉮

유저가 선택하지 않거나 "기본"이라고 답하면 1번(디폴트형)을 적용한다.

**올드형 선택 시 뎁스 체계:**
| 뎁스 | 클래스 | 딩뱃 기호 | 예시 |
|------|--------|-----------|------|
| 1 (대항목) | `item-1` | (가), (나), (다)… | `<div class="item-1">(가) 추진 배경</div>` |
| 2 (중항목) | `item-2` | ①, ②, ③… | `<div class="item-2">① 세부 내용임.</div>` |
| 3 (소항목) | `item-3` | ㉮, ㉯, ㉰… | `<div class="item-3">㉮ 상세 항목임.</div>` |

올드형에서는 각 뎁스 내에서 항목 순서에 따라 기호가 순차 증가한다.

### 3단계: 컬러 프리셋 선택

`options/color-presets.md`를 참조하여 유저에게 테이블 색상을 질문한다.

> 테이블 색상을 선택해주세요.
> 1. 기본 (회색)
> 2. 블루
> 3. 네이비
> 4. 그린
> 5. 다크
> 6. 커스텀 (직접 HEX 입력)

유저가 선택하지 않거나 "기본"이라고 답하면 1번을 적용한다.

### 4단계: 서식 변환

`references/formatting-guide.md`의 규칙에 따라 유저 텍스트를 HTML로 변환한다. 핵심 규칙 요약:

**구조 뎁스** — 3단계 들여쓰기 체계
- 뎁스 1: `<div class="item-1">ㅁ 텍스트</div>`
- 뎁스 2: `<div class="item-2">ㅇ 텍스트</div>`
- 뎁스 3: `<div class="item-3">- 텍스트</div>`

**테이블** — 비교·대조, 정형 데이터 등 명확한 경우에만 사용. 단순 설명은 문단형 서술 유지.

**HWP 호환 핵심** — HWP에 붙여넣기했을 때 서식이 유지되려면:
- 인라인 스타일 최소화, 클래스 기반 스타일링
- `<table>` 태그에 `border-collapse: collapse` 사용
- 폰트는 `맑은고딕` 기본, `pt` 단위 사용
- 이미지는 `<img>` 태그에 width/height 명시
- CSS `display: inline-table`로 테이블이 텍스트 흐름 속에 위치하도록 처리

**구성도(추진조직표)** — 조직도·추진체계도처럼 위계가 아래로 갈라지는 그림은 평면 표로 만들지 않는다. `references/org-chart.md`를 읽고 `scripts/orgchart.py`로 표를 생성한다.
- 유저 원고(메모·이미지)의 상자와 연결 관계를 spec.json으로 옮기고, 생성된 `<table data-orgchart="1">`을 본문 `item-3` 안에 넣는다.
- 열 폭은 생성기가 눈금 행의 `width` 속성으로 고정한다. `<colgroup>`으로 폭을 잡지 않는다(HWP가 무시).
- 결과를 브라우저 인쇄 미리보기로 확인해, 좁은 상자에서 글자가 넘치면 `\n` 줄바꿈이나 `slots`로 폭을 조정한다.

### 5단계: 출력

1. `templates/base.html`의 `{{CONTENT}}` 자리에 변환된 본문을 삽입한다.
2. 선택된 컬러 프리셋을 style 태그에 반영한다.
3. 단일 `.html` 파일로 저장한다.
4. **반드시** 툴바를 넣는다: `python3 scripts/add_toolbar.py 저장한파일.html`
   - 화면 위 고정 툴바: 본문 글자·표 글자 크기 −/+ (0.5pt 단위), 원래 크기, 안내 상자 숨기기, **본문 복사**
   - 본문 복사: 툴바와 `.guide` 안내 상자를 빼고 본문만 선택해 복사한다. 유저는 한글에 바로 붙여넣으면 된다.
   - 표 폭: 브라우저가 잡은 실제 폭을 모든 셀의 `width` 속성으로 고정한다(HWP는 CSS 폭을 무시하고 `width` 속성을 따름). 머리행 없는 표, colspan·rowspan 표도 맞는다. 구성도 표(`data-orgchart`, `.oc`)는 건드리지 않는다.
   - 삽입 위치·작업 안내처럼 붙여넣지 않을 문구는 `<div class="guide">`로 감싼다(본문 최상위, `.guide` 스타일은 문서에서 정의). 본문 복사에서 자동으로 빠지고, 상자마다 **이 블록 복사** 버튼이 생겨 다음 안내 상자 앞까지만 복사된다.
   - 이미 툴바가 있는 파일에 다시 실행해도 최신 조각으로 바뀌고, 예전 표 폭 스크립트는 지워진다.
5. 유저에게 파일 경로를 알려준다.
